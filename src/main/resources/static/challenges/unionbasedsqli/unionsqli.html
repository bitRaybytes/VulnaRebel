UNION-based SQL Injection

Stack, unite, and conquer backend vulnerabilities.

Difficulty: Medium


Objective:
The search functionality retrieves products from the database. However, the application may trust user input more than it should.

Your task is to identify the SQL injection point, determine the query structure, and use UNION SELECT to combine your own query with the original one.

Retrieve the hidden value stored inside the database and submit the flag.

The search functionality displays information retrieved from the database.
What happens if you can influence the query instead of only searching for products?

More hints

The application executes a query similar to:
SELECT name, category, price, description FROM products WHERE name LIKE '%your_input%'

The database expects a specific number of columns in the result. Can you find out how many columns the original query returns?

One more hint

Research how UNION SELECT combines results from multiple queries.

Your injected query must return the same number of columns as the original query. Start by testing with NULL values and identify which columns are displayed.

Once you know which columns are reflected, look for other tables that may contain interesting information.
